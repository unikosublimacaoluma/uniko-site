Política de Privacidade

A UNIKO Personalizados respeita a privacidade dos clientes e utiliza os dados pessoais apenas para atendimento, orçamento, produção, pagamento, entrega e relacionamento relacionados aos pedidos.

Dados que podemos receber

Podemos receber informações como nome, telefone, e-mail, endereço, dados do pedido, arquivos enviados pelo cliente, artes, logotipos, fotos e outras informações necessárias para preparar ou entregar um produto personalizado.

Como os dados são usados

Os dados podem ser usados para responder contatos, elaborar orçamentos, confirmar pedidos, produzir itens personalizados, organizar pagamentos, realizar entregas, prestar suporte e cumprir obrigações legais.

Compartilhamento

Quando necessário para concluir um pedido, algumas informações podem ser compartilhadas com serviços de pagamento, transporte, hospedagem, comunicação ou fornecedores envolvidos na execução do serviço. A UNIKO não vende dados pessoais de clientes.

WhatsApp e redes sociais

O site possui links para WhatsApp e redes sociais. Ao utilizar esses serviços, o tratamento de dados também pode estar sujeito às políticas das respectivas plataformas.

Segurança e conservação

Adotamos medidas razoáveis para proteger as informações recebidas. Os dados são mantidos pelo período necessário para atendimento, histórico do pedido e cumprimento de obrigações aplicáveis.
